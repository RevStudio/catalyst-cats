# Catalyst Cats — web build

**Play in your browser:** https://revstudio.github.io/catalyst-cats/

A cute magic-cat survivors-like: move, let your spells auto-fire, mix elements into reactions.
Controls: WASD / arrow keys (touch joystick on phones), spells cast automatically, ESC to pause.

This repository only hosts the compiled web build for GitHub Pages. The source code is private.
